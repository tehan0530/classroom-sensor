教室感測器

用手機當感測節點：看動靜、聽音量、把數字送上雲端

⚠ 這個網頁不會上傳任何影像或聲音。
畫面與聲音都只在你自己的手機裡處理，離開手機的只有兩個數字：動靜指數與音量。 這件事在工程上叫邊緣運算，也是這個範例最重要的一課。

1感知層：開啟感測器

第一次會跳出權限詢問，按「允許」。 如果用電腦，會用電腦的視訊鏡頭與麥克風。
動靜指數　MOTION
0
音量　SOUND

目前：安靜
這兩條門檻是「人訂的」。這就是 IoT。 到了第 15–17 週，我們會讓這兩個數字改成從資料自己學出來 —— 那就變成 AIoT。

2網路層：把數字送上雲端

要做什麼去 thingspeak.com 註冊（免費），建一個 Channel， 兩個欄位分別叫 motion 和 sound，然後把 Write API Key 貼到下面。
免費限制每 15 秒最多送一次。所以下面預設就是 15 秒。
尚未開始上傳。沒有 API Key 也可以只看本地數字。

3應用層：紀錄

等待開始…
資料上去之後，在 ThingSpeak 的 Channel 頁面就會看到即時曲線； 把 Channel 設成公開，你就有一個可以貼進履歷的網址。
